# User Research Survey Template

## Survey Guidelines

### Structure
1. **Introduction** (1 section)
   - Purpose statement
   - Estimated completion time
   - Privacy notice

2. **Screening Questions** (2-3 questions)
   - Verify target user criteria
   - Disqualify non-target respondents

3. **Current Behavior** (4-6 questions)
   - How users currently solve the problem
   - Pain points and frustrations
   - Frequency of related activities

4. **Feature Evaluation** (5-8 questions)
   - Interest in proposed features
   - Priority ranking
   - Willingness to adopt

5. **Demographics** (3-4 questions)
   - Role/job function
   - Company size
   - Experience level

6. **Closing** (1-2 questions)
   - Open feedback
   - Follow-up interview opt-in

### Question Types (Preferred Mix)
- **Multiple choice**: 40% - Quick, quantifiable responses
- **Likert scale (1-5)**: 30% - Measure attitudes and satisfaction
- **Open-ended**: 20% - Rich qualitative insights
- **Ranking**: 10% - Prioritization data

### Tone & Voice
- Professional but conversational
- Clear, jargon-free language
- Neutral phrasing (avoid leading questions)
- Respectful of respondent's time

### Length
- Target: 12-15 questions
- Completion time: 5-7 minutes
- Progress indicator: Show percentage complete

### Formatting
- One question per page for mobile
- Required questions marked with asterisk (*)
- Skip logic where appropriate
- Randomize option order to reduce bias
